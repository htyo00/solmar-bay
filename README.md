# SOLMAR BAY — open-world crime: steal cars, outrun the law, run the city

[![rank](https://make.fun/badge/gta6-01/htyo00/solmar-bay/rank.svg)](https://make.fun/bounty/gta6-01)
[![reward](https://make.fun/badge/gta6-01/htyo00/solmar-bay/reward.svg)](https://make.fun/bounty/gta6-01)

An open-world crime game for [make.fun's Make GTA 6 bounty](https://make.fun/bounty/gta6-01): a sun-soaked modern city, **Solmar Bay**, starring **Dante Cross**. Drive and steal cars, dodge traffic and pedestrians, outrun the police as your wanted level climbs, and run missions across the city — all playable offline in a desktop browser from static files, keyboard and mouse.

- 3D city on foot and by car (three.js)
- Traffic, pedestrians, stealable cars (E)
- Wanted level 1–5 and police chases
- Named missions and a story, HUD with minimap, start screen and save
